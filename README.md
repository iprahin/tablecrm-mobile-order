# TableCRM Mobile Order

Мобильная webapp-форма для создания заказа/продажи в TableCRM.

## Stack

- Next.js
- TypeScript
- App Router
- shadcn/ui
- Tailwind CSS
- TanStack Query
- React Hook Form / Zod-ready architecture
- Next Route Handlers as API proxy

## Features

- Ввод token кассы
- Загрузка справочников TableCRM
- Поиск клиента по телефону
- Выбор счёта
- Выбор организации
- Выбор склада
- Выбор типа цены
- Поиск товаров
- Корзина
- Скидки по позициям
- Поддержка карты лояльности
- Настройки повтора заказа
- Создать продажу
- Создать и провести продажу
